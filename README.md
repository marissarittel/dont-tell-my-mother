# What's your romantasy name?

A free, five-question quiz from **Don't Tell My Mother**, hosted by Indie Thorpewood.

The whole quiz lives in `index.html`. To change wording, questions, results or book picks, edit the clearly marked **EDITABLE CONTENT** section near the top of that file.

Before connecting subscriptions, add the Substack subscribe link to `substackUrl` in the same section.
